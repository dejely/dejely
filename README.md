## About Me

I'm a **Computer Science undergraduate at UP Visayas** with a strong interest in **cybersecurity, digital forensics, secure systems, and full-stack development**.

I like working on systems from both sides:  
building applications, understanding how they fail, and learning how to secure them better.

My current work focuses on:

- Ethical cybersecurity research and reconnaissance
- Web application security and vulnerability reporting
- Full-stack web development
- System architecture and backend design
- Linux-based development environments
- Computer vision and automation experiments

A lot of my work is private or academic, but I actively build projects around real-world systems, security, and developer tools.
